Philosophy

Built from scratch.
No bloat. No compromise.

Operating systems used to be understandable from top to bottom. Modern Linux distributions became weighed down with bloated init systems, 400MB node_modules, and opaque background daemons. FOID solves this by building everything cleanly from source.

00 Toolchain

musl-cross-make

Compiled with a dedicated x86_64-linux-musl cross-toolchain. All binaries are 100% statically linked: zero dynamic linker runtime overhead, zero missing library surprises.

01 Monolithic Kernel

Linux 6.18 LTS

Custom kernel configuration with all storage, filesystem, and networking drivers compiled straight into vmlinuz (=y). No kernel modules to load or break.

02 Core Userland

Static BusyBox

Provides standard POSIX userland, ash shell, and udhcpc DHCP client within a single static binary for both the initramfs and the live root.

03 PID 1 Init

runit & foidinit

True UNIX service supervision by Gerrit Pape. Stage banners by foidinit, instant bootup in under 1 second, and zero systemd complexity.

04 Bootloader

Limine Hybrid Boot

Modern, rock-solid bootloader supporting BIOS and modern 64-bit UEFI hybrid boot from a single unified ISO image.

05 Live Storage

RAM OverlayFS

The live root filesystem runs from an xz-compressed Squashfs image mounted with a tmpfs overlay in RAM. Nothing is written to your disks unless you choose to.

Install & Try

Install FOID Linux
(or try it first)

Boot the preview live system inside QEMU, flash it to a bootable USB drive, or build the entire distribution from scratch.

Shell — Boot hybrid ISO in QEMU 
# Run in QEMU with KVM acceleration:
qemu-system-x86_64 -m 2G -enable-kvm -cdrom foid-linux.iso

# For UEFI mode testing:
FOID_UEFI=1 ./test-iso.sh
Credentials: Log in as root (no password required). Run foidfetch and help.
Shell — Write directly to flash drive 
# Verify the block device name with lsblk first:
lsblk

# Write the hybrid ISO directly to the USB stick (erases the stick):
sudo dd if=foid-linux.iso of=/dev/sdX bs=4M status=progress conv=fsync
Note: Turn Secure Boot OFF in your BIOS/UEFI (the Limine bootloader is not Microsoft-signed). Ventoy users: select Normal mode.
Shell — End-to-end reproducible build 
# 1. Clone repository
git clone https://github.com/foidlinux/foidlinux ~/foid
cd ~/foid

# 2. Build everything from scratch (toolchain, kernel, busybox, runit, apps, ISO)
./build-all.sh

# 3. Boot test ISO in QEMU
./test-iso.sh
Dependencies: Linux host with base-devel, curl, xz, bzip2, squashfs-tools, libisoburn, cpio, and limine.

Roadmap

Where FOID is heading

Current status is 0.1-preview: a live text-mode system. Here is what is on the roadmap for upcoming releases.

v0.1-preview (Available)

From-scratch musl toolchain, Linux 6.18 LTS, static BusyBox, runit PID 1, Limine hybrid ISO, DHCP networking, nano, htop, curl, git, dropbear.

foidwm Window Manager

Our own custom Wayland window manager, keyboard-first by design ("the mouse is strictly for web browsers and gaming").

foidinit

A native, ultra-minimal init system tailor-made for FOID Linux to replace upstream runit orchestration stages.

Go Package Manager

A lightning-fast, reproducible package manager written in Go with static binary receipts and zero dynamic library collisions.

Graphical Session

Sway / wlroots Wayland session on static musl as a stable stepping stone toward a full standalone graphical environment.

Bare-Metal Installer

A swift TUI installer allowing users to install FOID Linux permanently to NVMe, SSD, or disk partitions.
